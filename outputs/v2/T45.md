Primary Key क्या होती है?

मान लीजिए आपके कॉलेज में हज़ारों स्टूडेंट्स पढ़ते हैं। अब सोचिए, दो बच्चों का नाम "राहुल शर्मा" हो सकता है, उनके पिता का नाम भी एक जैसा हो सकता है, और शायद वे एक ही शहर से भी हों।

इसी समस्या को हल करने के लिए हर स्टूडेंट को एक यूनीक Enrollment Number या Roll Number दिया जाता है। Roll Number कभी भी दो बच्चों का सेम नहीं हो सकता। बस! यही जो यूनीक पहचान है, डेटाबेस की भाषा में इसी को हम Primary Key कहते हैं।

आसान शब्दों में कहें तो: Primary Key डेटाबेस की टेबल का वो कॉलम (Column) होता है जो हर एक रिकॉर्ड (Row) को बिल्कुल अलग और यूनीक तरीके से पहचानता है।

Primary Key की दो सबसे बड़ी शर्तें (Rules)

जब भी आप किसी टेबल में Primary Key बनाते हैं, तो डेटाबेस दो पक्की शर्तें लागू करता है:

यह कभी खाली नहीं हो सकती (No NULL values): आप ऐसा नहीं कर सकते कि किसी रिकॉर्ड के लिए Primary Key की जगह खाली छोड़ दें। हर रो (Row) के पास अपनी यूनीक ID होनी ही चाहिए।

यह कभी डुप्लीकेट नहीं हो सकती (Must be Unique): एक बार जो ID किसी को मिल गई, वही ID दोबारा किसी और को नहीं मिल सकती। अगर गलती से भी आप दो अलग-अलग लोगों को एक ही Primary Key देना चाहेंगे, तो डेटाबेस तुरंत एरर (Error) फेंक देगा और मना कर देगा।
