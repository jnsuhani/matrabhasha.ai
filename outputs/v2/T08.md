Recursion का सीधा मतलब है **जब कोई function खुद को ही call करता है** किसी problem को solve करने के लिए।

अगर आप C या Python में loops और functions जानते हैं, तो आपके लिए recursion समझना बहुत आसान है। Loop में हम किसी block of code को repeat करने के लिए `for` या `while` यूज़ करते हैं, जबकि recursion में वही repetition **function stack** के ज़रिए हासिल किया जाता है।

### Core Mechanics: Recursion काम कैसे करता है?

हर recursive function दो ज़रूरी हिस्सों में बँटा होता है:

1. **Base Case:** वो condition जहाँ recursion रुकता है। अगर आप Base Case लगाना भूल गए, तो आपका function endless call होता रहेगा और अंत में **Stack Overflow** error दे देगा।

2. **Recursive Step:** जहाँ function खुद को नए, छोटे input के साथ दोबारा call करता है, ताकि वो Base Case की तरफ बढ़ सके।

### Call Stack और Memory Execution

जब भी कोई function call होता है, OS उसके लिए **Call Stack** पर एक नया **Stack Frame** बनाता है। Stack frame में function के parameters, local variables और return address store होते हैं।

Factorial का एक simple Python example देखते हैं:

```python
def factorial(n):
    # 1. Base Case
    if n <= 1:
        return 1
    # 2. Recursive Step
    return n * factorial(n - 1)
```

जब आप `factorial(3)` call करते हैं, तो memory में execution दो phases में होता है:

#### 1. Winding Phase (Pushing to Stack)

Function सब-प्रॉब्लम्स बनाते हुए stack पर चढ़ता जाता है:

- `factorial(3)` call हुआ → Stack पर push हुआ → Wait कर रहा है `3 * factorial(2)` पर।

- `factorial(2)` call हुआ → Stack पर push हुआ → Wait कर रहा है `2 * factorial(1)` पर।

- `factorial(1)` call हुआ → Base Case hit हुआ! यह सीधे `1` return करता है।

#### 2. Unwinding Phase (Popping from Stack)

Base case मिलते ही results पीछे की तरफ resolve (evaluate) होना शुरू होते हैं:

- `factorial(1)` return करता है `1` `factorial(2)` को।

- `factorial(2)` compute करता है `2 * 1 = 2` और return करता है `factorial(3)` को।

- `factorial(3)` compute करता है `3 * 2 = 6` और final result return कर देता है।

### Head Recursion vs Tail Recursion

Intermediate level पर यह समझना बहुत जरूरी है कि recursion किस टाइप का है:

- **Head Recursion:** अगर recursive call करने के बाद भी function में कुछ काम या computation बाकी रह जाता है (जैसे ऊपर दिए factorial वाले code में `n *` होना बाकी था)।

- **Tail Recursion:** अगर recursive call function की **आखिरी statement** हो और उसके बाद कोई pending operation न बचे।

**Tail Recursion का Example:**

```python
def tail_factorial(n, accumulator=1):
    if n <= 1:
        return accumulator
    # Pure recursive call with updated accumulator - final step
    return tail_factorial(n - 1, n * accumulator)
```

> **Why Compiler Optimization Matters (Tail Call Optimization - TCO):**
> modern compilers/interpreters (जैसे C का `gcc -O2`) Tail Recursion को पहचान लेते हैं। वो जानते हैं कि return के बाद पिछला stack frame सहेज कर रखने की ज़रूरत नहीं है। इसलिए वो Stack Frames को reuse कर लेते हैं, जिससे space complexity O(n) से घटकर O(1) हो जाती है और stack overflow का खतरा खत्म हो जाता है। (Note: Standard Python native TCO support नहीं करता, लेकिन C/C++/Scheme जैसे languages में यह काफी महत्वपूर्ण है)।

### Time and Space Complexity Analysis

Loops की तुलना में Recursion हमेशा extra memory ले जाता है:

| Parameter | Iteration (Loop) | Recursion |
|---|---|---|
| **Time Complexity** | O(n) (Direct iteration) | O(n) (Linear recursion में) |
| **Space Complexity** | O(1) (auxiliary variables call stack यूज़ नहीं करते) | O(n) (Call stack frames के कारण) |

*Dynamic Programming और Tree Traversal (DFS) जैसे advanced algorithms में Recursion सबसे नेचुरल और intuitive approch मानी जाती है, लेकिन iterative solutions हमेशा memory-friendly होते हैं।*
