###  Array क्या होता है? (Technical Definition)

मेमोरी (Memory) के स्तर पर बात करें, तो **Array** एक ही डेटा टाइप (Data Type) की वैल्यूज़ का एक **contiguous (लगातार/क्रमागत) मेमोरी ब्लॉक** होता है।

जब आप एक साधारण वेरिएबल बनाते हैं, तो वह मेमोरी में कहीं भी एक सिंगल वैल्यू स्टोर करता है। लेकिन जब आपको एक ही नाम के तहत कई सारी वैल्यूज़ स्टोर करनी हों, तब हम Array का उपयोग करते हैं।

---

###  मेमोरी में Array कैसे काम करता है?

Array की सबसे बड़ी खासियत इसका **Index-based Access** है। आइए इसे समझें:

* **0-based Indexing:** ज़्यादातर प्रोग्रामिंग भाषाओं (जैसे C, C++, Java, Python की लिस्ट) में एरे का पहला एलिमेंट इंडेक्स `0` से शुरू होता है।
* **Memory Address Calculation:** चूंकि एरे के सारे एलिमेंट्स मेमोरी में एक के बाद एक लाइन से स्टोर होते हैं, इसलिए कंपाइलर के लिए किसी भी एलिमेंट का एड्रेस ढूंढना बेहद आसान होता है।

मान लीजिए आपके पास एक इंटीजर एरे है:

```c
int marks[5] = {85, 90, 78, 92, 88};

```

यदि `marks[0]` का मेमोरी एड्रेस `1000` है, और एक इंटीजर `4` बाइट्स लेता है, तो `marks[1]` अपने आप `1004` पर होगा, `marks[2]` `1008` पर, और इसी तरह आगे बढ़ेगा।

---

### Array के मुख्य फायदे (Advantages)

1. **Random Access (O(1) Time Complexity):** आप किसी भी इंडेक्स नंबर का इस्तेमाल करके सीधे उस पोजीशन पर जा सकते हैं। जैसे `marks[3]` लिखने से सीधे चौथे एलिमेंट पर पहुँच जाएंगे—इसके लिए लूप चलाने की ज़रूरत नहीं है।
2. **Cache Locality:** क्योंकि सारा डेटा मेमोरी में पास-पास (contiguous) रखा होता है, इसलिए CPU का कैश (Cache) इसे बहुत तेजी से रीड कर पाता है, जिससे परफॉर्मेंस बेहतरीन मिलती है।

---

###  Array की सीमाएँ (Limitations)

इंटरमीडिएट लेवल पर यह समझना बहुत ज़रूरी है कि एरे की कुछ कमियाँ भी होती हैं:

* **Fixed Size:** एक बार आपने Array डिक्लेयर कर दिया (जैसे 5 साइज का), तो रन-टाइम पर आप उसका साइज बढ़ा या घटा नहीं सकते। अगर साइज़ कम पड़ गया, तो नया बड़ा एरे बनाना पड़ता है।
* **Costly Insertion/Deletion:** अगर आप बीच में (मान लीजिए इंडेक्स `1` पर) कोई नया एलिमेंट जोड़ना चाहें, तो बाकी के सभी एलिमेंट्स को एक-एक कदम आगे खिसकाना (shift करना) पड़ेगा, जिसमें समय लगता है (Time Complexity $O(N)$ हो जाती है)।

###  एक छोटा सा कोड उदाहरण (C / C++ स्टाइल)

आइए देखते हैं कि लूप की मदद से एरे को कैसे ट्रैवर्स (traverse) किया जाता है:

```c
#include <stdio.h>

int main() {
    // 4 साइज़ का एरे डिक्लेयर और इनिशियलाइज किया
    int scores[4] = {45, 60, 75, 90};

    // लूप की मदद से हर एलिमेंट को प्रिंट करना
    for(int i = 0; i < 4; i++) {
        printf("Index %d par value hai: %d\n", i, scores[i]);
    }
    
    return 0;
}

```
