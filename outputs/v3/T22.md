### 1. आसान भाषा में समझो

Stack (एक सिरे से जुड़ने और निकलने वाला डेटा क्रम) LIFO (सबसे बाद में आने वाला तत्व सबसे पहले बाहर निकलना) नियम पर चलता है। मुख्य operations हैं push (ऊपर element जोड़ना), pop (ऊपर का element हटाकर लौटाना) और peek या top (हटाए बिना सबसे ऊपर वाला element देखना)। खाली stack पर pop करने से underflow होता है, और तय आकार वाले stack के भर जाने पर push करने से overflow। Array (क्रमागत डेटा सूची) या linked list (कड़ियों से जुड़ी सूची) से stack बने हो, तो push, pop और peek का समय O(1) रहता है।

```python
s = []
s.append(10)
s.append(20)
print(s.pop())
print(s[-1])

```

यहाँ list के आखिर को top मानकर `append` से push, `pop` से pop और `s[-1]` से peek किया गया है; stack खाली होने पर `pop` या `s[-1]` से error आता है।

### 2. रोज़मर्रा की ज़िंदगी से मिसाल

चाय की दुकान पर एक के ऊपर एक रखी स्टील की प्लेटों का ढेर सोचो। नई प्लेट ऊपर रखते हैं और ग्राहक को ऊपर से उठाकर देते हैं। यह मिसाल कहाँ टूटती है: दुकानदार नीचे से भी प्लेट निकाल सकता है, जबकि stack सिर्फ़ top से काम करता है।

### 3. ज़रूरी शब्द

* **LIFO** – सबसे बाद में आया element सबसे पहले बाहर निकलना
* **peek** – बिना हटाए सबसे ऊपर का element देखना
* **overflow** – भरे हुए stack में नया element डालने की स्थिति
* **underflow** – खाली stack से element निकालने की स्थिति

### 4. आम गलतफ़हमी

**गलतफ़हमी:** Stack में बीच या नीचे के element को सीधे पढ़ना या हटाना संभव है। **सही बात:** मानक stack में पहुँच सिर्फ़ top तक सीमित है; नीचे पहुँचने के लिए ऊपर के elements को pop करना पड़ता है।
