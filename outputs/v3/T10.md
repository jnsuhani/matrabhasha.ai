### 1. आसान भाषा में समझो

Array (लगातार जगह में रखे एक ही तरह के डेटा का संग्रह) memory में एक साथ जुड़े हुए blocks में elements (डेटा की इकाइयाँ) रखता है। हर block का एक index (स्थान बताने वाली क्रम-संख्या) होता है, जो आम तौर पर 0 से शुरू होकर length - 1 तक जाता है। आधार पता और index जोड़कर सीधे किसी भी element तक पहुँचा जा सकता है, इसलिए random access (सीधे किसी भी जगह का डेटा पढ़ना या बदलना) का time complexity O(1) होता है। बीच में insertion (नया element डालना) या deletion (element हटाना) करने पर बाकी elements खिसकाने पड़ते हैं, जिससे O(n) समय लग सकता है। Array खाली हो या पूरा भर जाए तो आकार की सीमा आड़े आती है, और गलत index देने पर out-of-bounds (सीमा से बाहर जाने की) स्थिति बनती है।

```c
int arr[4] = {10, 20, 30, 40};
int total = 0;
for (int i = 0; i < 4; i++) {
    total += arr[i];
}

```

यहाँ loop index 0 से 3 तक चलकर हर element को total में जोड़ता है।

### 2. रोज़मर्रा की ज़िंदगी से मिसाल

रेलवे के कोच में एक के पीछे एक जुड़ी सीटें 1, 2, 3 नंबर से होती हैं। यह मिसाल कहाँ टूटती है: असली कोच की सीटें 1 से शुरू होती हैं, जबकि array का index आम तौर पर 0 से शुरू होता है।

### 3. ज़रूरी शब्द (Key Terms)

* **Array** – लगातार memory में रखे एक ही तरह के elements
* **Index** – array के भीतर element की स्थिति बताने वाली संख्या
* **Random access** – index से सीधे किसी भी element तक पहुँचना
* **Out-of-bounds** – मान्य index सीमा के बाहर जाने की स्थिति

### 4. आम गलतफ़हमी

**गलतफ़हमी:** Array का पहला element हमेशा index 1 पर होता है। **सही बात:** ज़्यादातर भाषाओं में पहला element index 0 पर होता है और n आकार वाले array का आखिरी index n - 1 होता है।
