1. आसान भाषा में समझो
Database (डेटा सुरक्षित रखने वाली जगह) की table (जानकारी की लिस्ट) में primary key (हर रिकॉर्ड की अनोखी पहचान) एक ऐसा column (लिस्ट का खंभा) होता है जो हर row (जानकारी की एक लाइन) को पहचान देता है। इसकी दो मुख्य शर्तें होती हैं: पहिली, इसमें कभी duplicate (एक जैसी) value नहीं हो सकती। दूसरी, यह कभी NULL (खाली या बिना जानकारी वाला) नहीं हो सकता। एक table में सिर्फ़ एक ही primary key हो सकती है। अगर डेटा न मिला या खाली छूटा, तो रिकॉर्ड ढूँढना नामुमकिन हो जाता है।

2. रोज़मर्रा की ज़िंदगी से मिसाल
स्कूल में हर बच्चे को मिला Roll number (रोल नंबर)। दो बच्चों का रोल नंबर एक जैसा नहीं हो सकता और किसी बच्चे का रोल नंबर खाली नहीं छोड़ा जाता। यह मिसाल कहाँ टूटती है: स्कूल बदलने पर दूसरा स्कूल वही रोल नंबर किसी और बच्चे को दे सकता है, पर database में primary key पूरी table में हमेशा अनोखी रहती है।

3. ज़रूरी शब्द (Key Terms)
Primary key – हर लाइन की अनोखी पहचान

Column – एक तरह की जानकारी का खंभा

Row – एक व्यक्ति या चीज़ की पूरी लाइन

NULL – खाली या बिना भरी हुई जगह

4. आम गलतफ़हमी
गलतफ़हमी: Primary key हमेशा कोई नंबर ही होना चाहिए। सही बात: यह नंबर, अक्षर या दोनों का मेल (जैसे ड्राइविंग लाइसेंस नंबर) भी हो सकता है, बस अनोखा होना चाहिए।
