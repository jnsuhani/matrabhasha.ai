नमस्ते! कंप्यूटर साइंस की दुनिया में आपका स्वागत है। आज हम Recursion (रिकर्शन) के बारे में बहुत ही आसान भाषा में समझेंगे।

Recursion (रिकर्शन) क्या है?
सरल शब्दों में कहें तो जब कोई फंक्शन (Function) अपने काम को पूरा करने के लिए खुद को ही बार-बार कॉल (Call) करता है, तो उसे Recursion कहते हैं।

इसे समझने के लिए एक वास्तविक जीवन का उदाहरण लेते हैं:

दर्पण वाला उदाहरण:
सोचिए आप दो आमने-सामने रखे शीशों (Mirrors) के बीच खड़े हैं। आपको शीशे के अंदर खुद की अनंत (infinite) तस्वीरें दिखने लगती हैं। एक तस्वीर के अंदर दूसरी तस्वीर, उसके अंदर तीसरी... यही रिकर्शन का मूल विचार है!
रिकर्शन के 2 सबसे महत्वपूर्ण हिस्से
किसी भी रिकर्सिव फंक्शन (Recursive Function) में दो मुख्य चीजें होती हैं, जिनके बिना प्रोग्राम सही से काम नहीं कर सकता:

1. Base Case (बेस केस - रुकने की शर्त):

   * यह वह शर्त है जो फंक्शन को बताती है कि "अब रुक जाओ, खुद को दोबारा कॉल मत करो!"

   * अगर हम Base Case नहीं लगाएंगे, तो फंक्शन अनंत बार (infinitely) चलता रहेगा और आपका कंप्यूटर/प्रोग्राम क्रैश हो जाएगा (जिसे Stack Overflow कहते हैं)।

2. Recursive Case (रिकर्सिव केस - आगे बढ़ने का काम):

   * यह वह हिस्सा है जहाँ फंक्शन समस्या को थोड़ा छोटा करता है और खुद को फिर से कॉल करता है।

एक आसान कोड उदाहरण: उल्टी गिनती (Countdown)
आइए C++ / Java / Python की तर्ज पर एक बहुत ही आसान उदाहरण देखें जो `5` से लेकर `1` तक गिनती प्रिंट करता है:

Python

```
def countdown(n):
    # 1. Base Case (रुकने की शर्त)
    if n <= 0:
        print("Done!")
        return

    # 2. काम करना (Print करना)
    print(n)

    # 3. Recursive Case (फंक्शन का खुद को कॉल करना)
    countdown(n - 1)


# फंक्शन को कॉल करना
countdown(3)

```

यह पीछे कैसे काम करता है?

1. आपने `countdown(3)` को कॉल किया ➔ यह `3` प्रिंट करता है और फिर `countdown(2)` को कॉल करता है।

2. `countdown(2)` ➔ यह `2` प्रिंट करता है और फिर `countdown(1)` को कॉल करता है।

3. `countdown(1)` ➔ यह `1` प्रिंट करता है और फिर `countdown(0)` को कॉल करता है।

4. `countdown(0)` ➔ यहाँ Base Case (`n <= 0`) सही हो जाता है, यह `"Done!"` प्रिंट करता है और रुक जाता है!

रिकर्शन का इस्तेमाल क्यों करते हैं?

* बड़ी समस्याओं को छोटा बनाना: जब किसी बड़ी समस्या को छोटे-छोटे समान भागों में तोड़ा जा सकता है (जैसे - फ़ैक्टोरियल निकालना, फ़िबोनैकी सीरीज़, या फोल्डर के अंदर फोल्डर खंगालना)।

* साफ़ और छोटा कोड: रिकर्शन का उपयोग करने से कोड काफी छोटा और पढ़ने में आसान हो जाता है।
