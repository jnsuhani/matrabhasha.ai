### Stack kya hota hai? (What is a Stack?)

**Stack** ek linear data structure hai jo ek **LIFO (Last In, First Out)** ke principle par kaam karta hai.

> **LIFO ka matlab:** Jo cheez **sabse aakhir mein** (last) aayegi, wohi **sabse pehle** (first) bahar jayegi.

Ise aap ek aasan udaharan se samajh sakte hain:

* **Plates ka dher (Pile of Plates):** Jab aap ek ke upar ek plates rakhte hain, toh sabse pehle aap niche wali plate nahi nikal sakte. Aapko **sabse upar wali (top)** plate ko hi sabse pehle uthana padega.

---

### Stack ke Mukhya Operations (Core Operations)

Intermediate level par, aapko pata hona chahiye ki Stack ke sath main kaunse operations kiye jaate hain:

1. **Push:** Stack ke sabse upar ek naya element add karna. (Agar stack bhar chuka hai, toh use **Overflow** kehte hain).
2. **Pop:** Stack ke sabse upar wale element ko hataana (remove karna). (Agar stack khali hai aur aap pop kar rahe hain, toh use **Underflow** kehte hain).
3. **Peek / Top:** Sirf yeh dekhna ki abhi stack ke sabse upar kaunsa element rakha hai, bina use remove kiye.
4. **IsEmpty:** Yeh check karna ki stack khali hai ya nahi.

---

### Computer Science mein Stack kahan use hota hai? (Applications of Stack)

1. **Function Call / Recursion (Call Stack):**
Jab aap ek function ke andar dusre function ko call karte hain, toh computer **Call Stack** ka use karta hai. Jab andar wala function khatam ho jata hai, tab control wapas purane function par laut aata hai.
2. **Undo aur Redo Operations:**
Aapne Microsoft Word ya Notepad mein **Ctrl + Z (Undo)** kiya hoga. Yeh saare actions ek stack mein store hote hain, isiliye sabse naya action sabse pehle undo hota hai.
3. **Expression Evaluation & Syntax Parsing:**
Compilers expressions (jaise `(A + B) * C`) ko check karne aur brackets (`()`, `{}`, `[]`) properly band hain ya nahi, yeh verify karne ke liye stack ka use karte hain.

### Ek Chhota sa Code Example (Python mein)

Aaiye dekhte hain ki Python mein aap ek simple Stack kaise bana sakte hain:

```python
# Ek khali list ko stack ki tarah use karna
stack = []

# 1. Push operation (Elements add karna)
stack.append(10)
stack.append(20)
stack.append(30)
print("Stack push ke baad:", stack)  # Output: [10, 20, 30]

# 2. Pop operation (Sabse aakhri element ko hatana)
popped_item = stack.pop()
print("Bahar aaya element (Popped):", popped_item)  # Output: 30
print("Stack pop ke baad:", stack)  # Output: [10, 20]

# 3. Peek operation (Top element dekhna)
top_element = stack[-1]
print("Top element (Peek):", top_element)  # Output: 20

```
