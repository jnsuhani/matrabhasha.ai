Ek Asli Zindagi ka Example (Real-Life Analogy)

Sochiye aapke paas ek badi Russian Nesting Doll hai. Jab aap use kholte hain, toh andar ek aur choti doll milti hai. Aap us choti doll ko kholte hain, toh uske andar aur choti doll milti hai. Aap tab tak doll kholte rehte hain jab tak sabse choti doll na mil jaye, jise aur nahi khola ja sakta. Yeh jo process hai — ek hi kaam ko baar-baar chote level par repeat karna — yahi Recursion hai!

Recursion ke 2 Sabse Main Parts:

Base Case (Rukne ki shart): Yeh sabse important rule hai! Agar aapne recursion mein rukne ki condition nahi di, toh function infinite baar khud ko call karta rahega aur computer ka memory crash ho jayegi (Stack Overflow). Base case batata hai ki kab rukna hai.

Recursive Step (Khud ko call karna): Yahan function main problem ko thoda chota karke khud ko dubara call karta hai.

Python mein ek chhota sa Beginner Example:

Aaiye ek countdown function dekhte hain jo 3 se lekar 0 tak ginta hai:

```python
def countdown(n):
    # 1. Base Case: Jab n, 0 par pahunch jaye toh ruk jao
    if n == 0:
        print("Blastoff! 🚀")
        return
    else:
        print(n)
        # 2. Recursive Step: Function khud ko call kar raha hai chote number ke sath
        countdown(n - 1)

# Function ko call karte hain
countdown(3)
```

Output kya aayega?

```text
3
2
1
Blastoff! 🚀
```
