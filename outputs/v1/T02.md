## For Loop Kya Hota Hai?
Intermediate level par, `for` loop ko hum "Sequence-based Iteration" ya "Definite Iteration" kehte hain. Iska matlab yeh hai ki aapko pehle se hi pata hota hai ki loop kitni baar chalega (fixed number of times), ya phir aap kisi collection (jaise list, string, ya range) ke har ek element par ek-ek karke ja rahe hain.

## Python Mein For Loop Ka Structure
Python mein `for` loop kaafireadable hota hai. Iska syntax kuch is tarah hota hai:

Python

```
for item in sequence:
    # Code jo har iteration mein chalega

```

Yahan:

* `sequence` woh object hai jisme multiple items hain (jaise `range(5)`, list `[1, 2, 3]`, ya string `"Hello"`).

* `item` ek temporary variable hai jo loop ke har ek round mein sequence ke agle element ko pakadta hai.

## Intermediate Examples
1. `range()` function ka advanced use (Step value ke sath)
Beginners aksar `range(n)` ka use karte hain. Intermediate level par hum `range(start, stop, step)` ka use karte hain:

Python

```
# 1 se lekar 10 tak, sirf even numbers (2-2 ke gap par) print karne ke liye
for num in range(2, 11, 2):
    print(num)

```

Output:

Plaintext

```
2
4
6
8
10

```

Yahan `2` start hai, `11` stop hai (11 se pehle ruk jayega), aur `2` step (increment) hai.

2. Collections/Lists par iteration
Jab aap kisi list ya dictionary par kaam karte hain, toh `for` loop data ko process karne mein madad karta hai:

Python

```
scores = [85, 90, 78, 92]
total = 0

for score in scores:
    total += score

average = total / len(scores)
print(f"Average Score: {average}")

```

3. `enumerate()` ka use (Index aur Value dono ke liye)
Intermediate level par yeh ek bahut hi useful function hai. Jab aapko loop ke andar item ke sath-sath uska index bhi chahiye ho:

Python

```
fruits = ["apple", "banana", "cherry"]

for index, fruit in enumerate(fruits):
    print(f"Index {index} par {fruit} hai.")

```

Output:

Plaintext

```
Index 0 par apple hai.
Index 1 par banana hai.
Index 2 par cherry hai.

```

## Important Control Statements (Loop ke andar)
Intermediate level par aapko in do keywords ka pata hona chahiye jo loop ke flow ko control karte hain:

1. `break`: Loop ko beech mein hi rokne ke liye agar koi specific condition match ho jaye.

2. `continue`: Current iteration ko skip karke seedhe agle iteration par jaane ke liye.

Python

```
for num in range(1, 6):
    if num == 3:
        continue  # 3 ko skip kar dega
    if num == 5:
        break     # 5 aate hi loop band ho jayega
    print(num)

```

Output:

Plaintext

```
1
2
4

```
