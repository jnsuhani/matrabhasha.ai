सोचिए, अगर आपको नोटबुक में अपना नाम 100 बार लिखने को कहा जाए, तो हाथ दर्द करने लगेगा और बहुत समय भी बर्बाद होगा। लेकिन कंप्यूटर से आप यही काम बस 2-3 लाइन का कोड लिखकर चुटकियों में करवा सकते हैं। इसी काम को आसान बनाने के लिए हम Loop (लूप) का इस्तेमाल करते हैं।

फॉर लूप (For Loop) क्या है?
जब हमें किसी कोड या इंस्ट्रक्शन (Instruction) को एक निश्चित बार (Fixed number of times) बार-बार दोहराना होता है, तब हम For Loop का इस्तेमाल करते हैं।

'Loop' का मतलब ही होता है एक ही रास्ते पर गोल-गोल घूमना, जब तक कि काम पूरा न हो जाए।

इसे एक आसान उदाहरण से समझें 🎡
मान लीजिए आप एक पार्क में दौड़ लगा रहे हैं और आपको 5 चक्कर पूरे करने हैं:

1. शुरुआत (Initialization): आप चक्कर नंबर 1 से शुरू करते हैं।

2. शर्त (Condition): आप तब तक दौड़ेंगे जब तक 5 चक्कर पूरे न हो जाएँ (क्या चक्कर <= 5 है?)।

3. गिनती बढ़ाना (Increment): हर एक चक्कर पूरा होने पर आप अपनी गिनती में +1 जोड़ लेते हैं।

कंप्यूटर में For Loop बिल्कुल इसी तरह काम करता है!

Python में For Loop कैसे लिखते हैं?
अगर हमें कंप्यूटर से 1 से लेकर 5 तक गिनती प्रिंट करवानी हो, तो कोड ऐसा दिखेगा:

Python

```
for i in range(1, 6):
    print(i)

```

आउटपुट:

Plaintext

```
1
2
3
4
5

```

यहाँ क्या हो रहा है?

* `for`: कंप्यूटर को बताता है कि हम लूप शुरू कर रहे हैं।

* `i`: यह एक वेरिएबल (Variable) है जो गिनती को याद रखता है (जैसे आपका चक्कर काउंटर)।

* `range(1, 6)`: इसका मतलब है 1 से शुरू करो और 6 से पहले (यानी 5 तक) रुक जाओ।

For Loop का असली फ़ायदा
अगर आपको screen पर "नमस्ते!" 5 बार छापना है:

* बिना फॉर लूप के:

Python

```
print("नमस्ते!")
print("नमस्ते!")
print("नमस्ते!")
print("नमस्ते!")
print("नमस्ते!")

```

* फॉर लूप के साथ:

Python

```
for i in range(5):
    print("नमस्ते!")

```

देखा कितना आसान हो गया? 5 बार की जगह 1000 बार भी लिखना हो, तो बस `range(1000)` लिखना पड़ेगा!
