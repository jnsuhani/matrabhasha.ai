इंटरमीडिएट लेवल पर, आइए इसे गहराई से समझें कि यह डेटाबेस में कैसे काम करती है और इसका क्या महत्व है।

Primary Key (प्राथमिक कुंजी) क्या है?

इंटरमीडिएट स्तर पर, Primary Key किसी डेटाबेस टेबल (Table) का वह स्तम्भ (Column) या स्तम्भों का समूह (Set of columns) होती है, जो टेबल के प्रत्येक रिकॉर्ड (Row) को पूरी तरह से अद्वितीय (Unique) रूप से पहचानती है।

इसे आसान शब्दों में कहें तो, यह डेटाबेस की वह आईडी है जो यह सुनिश्चित करती है कि टेबल में कोई भी दो रिकॉर्ड बिल्कुल एक जैसे या डुप्लीकेट न हों।

Primary Key की मुख्य विशेषताएं (Key Characteristics)

इंटरमीडिएट परीक्षा या इंटरव्यू के दृष्टिकोण से, Primary Key की दो सबसे बड़ी शर्तें (Constraints) होती हैं:

Unique (अद्वितीय): Primary Key के कॉलम में कोई भी वैल्यू दो बार नहीं आ सकती। हर एक वैल्यू पूरी तरह से अलग होनी चाहिए। (जैसे: अगर एक Student की ID 101 है, तो किसी और स्टूडेंट की ID 101 नहीं हो सकती)।

Not Null (रिक्त नहीं हो सकती): इस कॉलम का कोई भी सेल खाली (NULL) नहीं छोड़ा जा सकता। हर रिकॉर्ड के लिए Primary Key की वैल्यू होना अनिवार्य है।

💡 नोट: एक टेबल में केवल एक ही Primary Key हो सकती है, लेकिन वह Primary Key एक से ज्यादा कॉलम से मिलकर भी बन सकती है (जिसे हम Composite Primary Key कहते हैं)।

एक वास्तविक जीवन का उदाहरण (Real-world Example)

मान लीजिए आपके स्कूल का एक डेटाबेस है जिसमें Students नाम की एक टेबल है।

अगर आप नाम (Name) को Primary Key बनाते हैं, तो समस्या आ सकती है क्योंकि दो छात्रों का नाम "Amit" हो सकता है।

अगर आप मोबाइल नंबर (Phone Number) को चुनते हैं, तो कुछ छात्र ऐसे हो सकते हैं जिनके पास फोन न हो (जो NULL वैल्यू देगा)।

इसलिए, हम एक StudentID या RollNumber बनाते हैं:

हर छात्र का Roll Number अलग होता है (Unique)।

कोई भी छात्र बिना Roll Number के नहीं हो सकता (Not Null)।

अतः, RollNumber यहाँ एक परफेक्ट Primary Key है।

SQL में Primary Key कैसे बनाते हैं? (Code Example)

इंटरमीडिएट लेवल पर इसका सिंटैक्स जानना बहुत जरूरी है:

```sql
CREATE TABLE Students (
    RollNo INT PRIMARY KEY,
    StudentName VARCHAR(50),
    Email VARCHAR(100)
);
```

अगर आप टेबल पहले ही बना चुके हैं और बाद में Primary Key जोड़ना चाहते हैं, तो आप इस कमांड का उपयोग करेंगे:

```sql
ALTER TABLE Students
ADD CONSTRAINT PK_RollNo PRIMARY KEY (RollNo);
```

Primary Key और Foreign Key का संबंध

इंटरमीडिएट लेवल पर यह समझना भी जरूरी है कि Primary Key का उपयोग Foreign Key बनाने के लिए किया जाता है। जब एक टेबल की Primary Key को किसी दूसरी टेबल में कॉलम के रूप में रखा जाता है, तो वह दूसरी टेबल में Foreign Key बन जाती है। इससे दो टेबल के बीच संबंध (Relationship) स्थापित होता है (जैसे Students टेबल और Courses टेबल के बीच)।
