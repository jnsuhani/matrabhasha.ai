बाइनरी सर्च क्या है? (What is Binary Search?)
बाइनरी सर्च एक बहुत ही तेज़ सर्चिंग एल्गोरिदम (Searching Algorithm) है, जिसका उपयोग किसी सॉर्टेड (Sorted / क्रमबद्ध) लिस्ट या ऐरे (Array) में से किसी विशेष एलिमेंट (Element) को ढूंढने के लिए किया जाता है।

यह "Divide and Conquer" (बाँटें और राज करें) के सिद्धांत पर काम करता है। इसका मतलब है कि यह हर बार डेटा को आधे हिस्से में बांट देता है, जिससे समय की बहुत बचत होती है।

इंटरमीडिएट लेवल पर इसका कोड देखना इसे और स्पष्ट कर देगा:

def binary_search(arr, target):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2

        # अगर टारगेट बीच में मिल जाए
        if arr[mid] == target:
            return mid

        # अगर टारगेट, मिड से बड़ा है, तो लेफ्ट हाफ को छोड़ दें
        elif arr[mid] < target:
            low = mid + 1

        # अगर टारगेट, मिड से छोटा है, तो राइट हाफ को छोड़ दें
        else:
            high = mid - 1

    return -1 # अगर एलिमेंट लिस्ट में नहीं है

# उदाहरण:
numbers = [10, 23, 37, 45, 67, 89, 92]
target_value = 37

result = binary_search(numbers, target_value)
if result != -1:

else:
