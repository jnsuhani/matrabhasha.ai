# Word-for-word translation baseline (faculty's suggestion)

Faculty asked you to compare against "a basic word-for-word translation". Make it the same way for every concept:

1. In a fresh ChatGPT chat, send in English:
   `Explain {CONCEPT} for a {complete beginner with no programming background / learner who knows programming basics and wants technical depth}. Include an analogy, key terms, one common misconception and 2-3 practice questions.`
2. Copy the English answer into **Google Translate** (English → Hindi). Do not edit it.
3. Save the Hindi result in `outputs/` as condition **TR** (file name `Txx_TR.md`).

This shows what a student gets today from a translation tool, which is the gap your project claims to fill.
