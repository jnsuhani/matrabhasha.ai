# Few-shot examples (the team writes these, needed for v3)

Milestone 1 says the 2–3 examples are **written by our team**. So write them yourselves: pick a concept that is
**not** in the test set (otherwise the test is unfair), and use the exact 5 headings from v3.

Suggested example concepts (not in test set): **Variable**, **If-else statement**, **Compiler vs Interpreter**.

Assign: one member writes one example each, another member checks Hindi and accuracy.

## Template to fill

```
User: Concept: Variable | Level: Beginner

Matrabhāsha:
### 1. आसान भाषा में समझो
Computer को कई चीज़ें याद रखनी पड़ती हैं, जैसे किसी game का score। इसके लिए वो अपनी memory (याद रखने वाली जगह) में थोड़ी जगह लेकर उसे एक नाम दे देता है। इसी नाम वाली जगह को **variable** (नाम वाली जगह) कहते हैं, और उसमें रखी चीज़ को **value** (मान)। नाम वही रहता है, पर value बदल सकती है, जैसे हर चौके के साथ score बदलता है।

### 2. रोज़मर्रा की ज़िंदगी से मिसाल
सोचो, रसोई में डिब्बों पर नाम लिखे होते हैं: "चीनी", "चायपत्ती", "दाल"। "चीनी" वाले डिब्बे में आज आधा किलो है, कल शायद दो चम्मच बचें। नाम वही रहता है, अंदर की चीज़ बदलती है। Variable भी ऐसा ही है।
यह मिसाल कहाँ टूटती है: variable में नई value रखते ही पुरानी पूरी तरह हट जाती है, डिब्बे की तरह मिलती नहीं।

### 3. ज़रूरी शब्द (Key Terms)
- **Variable** – नाम वाली जगह, जिसमें एक value रखी जाती है
- **Value** – variable के अंदर रखी चीज़, जैसे कोई संख्या या नाम
- **Memory** – computer की वह जगह जहाँ वो चीज़ें याद रखता है

### 4. आम गलतफ़हमी
**गलतफ़हमी:** एक बार variable में value रख दी, तो वो हमेशा वही रहेगी।
**सही बात:** Value बदली जा सकती है, इसीलिए इसे "variable" (बदलने वाला) कहते हैं।

### 5. खुद से करके देखो (Practice)
1. Mobile पर दिखने वाला battery प्रतिशत variable जैसा कैसे है? उसका नाम और value क्या होगी?
2. अगर "score" नाम के variable में पहले 10 था और फिर उसमें 25 रखा गया, तो अब उसमें क्या है?
```

## Checklist before pasting an example into the prompt
- [ ] Every technical term is in English with a short Hindi gloss on first use
- [ ] Sounds like how you would explain it to a friend, read it aloud
- [ ] Analogy is Indian daily life and says where it breaks
- [ ] Length fits the level
- [ ] Checked for accuracy by a second member
