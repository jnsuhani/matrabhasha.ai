# Few-shot examples (the team writes these)

Milestone 1 says the 2–3 examples are **written by our team**. So write them yourselves: pick a concept that is
**not** in the test set (otherwise the test is unfair), and use the exact 5 headings from v1.

Suggested example concepts (not in test set): **Variable**, **If-else statement**, **Compiler vs Interpreter**.

Assign: one member writes one example each, another member checks Hindi and accuracy.

## Template to fill

```
User: Concept: Variable | Level: Beginner

Matrabhāsha:
### 1. आसान भाषा में समझो
...
### 2. रोज़मर्रा की ज़िंदगी से मिसाल
...
### 3. ज़रूरी शब्द (Key Terms)
- **variable** – ...
### 4. आम गलतफ़हमी
...
### 5. खुद से करके देखो (Practice)
1. ...
2. ...
```

## Checklist before pasting an example into the prompt
- [ ] Every technical term is in English with a short Hindi gloss on first use
- [ ] Sounds like how you would explain it to a friend, read it aloud
- [ ] Analogy is Indian daily life and says where it breaks
- [ ] Length fits the level
- [ ] Checked for accuracy by a second member
