# Few-shot examples (the team writes these, needed for v3)

Milestone 1 says the 2–3 examples are **written by our team**. So write them yourselves: pick a concept that is
**not** in the test set (otherwise the test is unfair), and use the exact 5 headings from v3.

Assign: one member writes one example each, another member checks Hindi and accuracy.

## Template to fill

```
User: Concept: Variable | Level: Beginner

Matrabhāsha:
### 1. आसान भाषा में समझो
Programming में **Variable** को एक नाम वाले डिब्बे की तरह समझो, जिसमें कोई value (मान) रखी जा सकती है। उदाहरण के लिए, `age = 20` में `age` variable का नाम है और `20` उसकी value है। जब हमें उम्र की ज़रूरत होती है, तो हम `age` का इस्तेमाल कर सकते हैं।

### 2. रोज़मर्रा की ज़िंदगी से मिसाल
मान लो तुम्हारे पास एक डिब्बा है जिस पर `age` लिखा है। तुम उसमें `20` रख देती हो। अब जब भी तुम्हें उम्र की ज़रूरत हो, तुम `age` नाम देखकर उसकी value इस्तेमाल कर सकती हो।
Programming में भी variable का नाम हमें उसकी value इस्तेमाल करने में मदद करता है।
ध्यान रहे, यह सिर्फ समझने के लिए एक मिसाल है। Programming में variable कोई असली डिब्बा नहीं होता।

### 3. ज़रूरी शब्द (Key Terms)
- **Variable** — किसी value को नाम के ज़रिए इस्तेमाल करने का तरीका।
- **Value** — वह data जो variable से जुड़ा होता है, जैसे `20`।
- **Assignment** — variable को कोई value देना, जैसे `age = 20`।
- **Data Type** — data किस तरह का है, जैसे `integer` (पूर्ण संख्या)।

### 4. आम गलतफ़हमी
- **गलतफ़हमी 1:** Variable की value हमेशा same रहती है।
  **सही बात:** कई programming languages में variable की value बदली जा सकती है।

- **गलतफ़हमी 2:** `age = 20` का मतलब है कि `age` और `20` mathematically बराबर हैं।
  **सही बात:** Python जैसी language में `=` assignment operator है, जो variable को value देता है।

### 5. खुद से करके देखो (Practice)
1. इस code में variable का नाम और उसकी value पहचानो: `marks = 85`
2. Python में `city` नाम का variable बनाओ और उसमें अपने शहर का नाम store करो।
```
