# 90–150 second video script (M2 component, 2 marks)

Target: **about 2 minutes**. Record your screen (OBS, Windows Game Bar `Win+G`, or Mac `Cmd+Shift+5`) and record voice over it.
**Amna** narrates and records. If you can, let each of the other members appear for a few seconds (for example on the title
slide or saying the one line about their part), since contribution by every member is assessed.

| Time | On screen | Voice (say it in your own words, Hindi or English) |
|---|---|---|
| 0:00–0:15 | Title slide: "Matrabhāsha – Team SyntaxAI" + team names | "Many Hindi-comfortable learners, like Hindi-medium first-year students, struggle when CS is taught only in English. Translation tools give stiff Hindi. We built Matrabhāsha to fix that with prompt engineering." |
| 0:15–0:30 | M1 baseline output and Google Translate output side by side, highlight a stiff line | "This is what a simple prompt and Google Translate give. Words like 'पुनरावर्तन' that no student uses, and no sense of the student's level." |
| 0:30–0:50 | `design/workflow.png`, then the version ladder from `design/design.md` | "We built the prompt in steps. v1 added only a teacher role and the student's level. Our v1 tests showed [real v1 failure], so v2 added [the fix, e.g. natural Hindi and English terms]. A second reviewer prompt checks each answer, and a team member does a final check." |
| 0:50–1:20 | Live Gem on v2: `Concept: Stack \| Level: Beginner`, then Intermediate | "Same concept, two levels, based on what you already know, not your year." Then point out the real difference you see between the two answers (depth, examples, code). |
| 1:20–1:35 | Reviewer Gem returning JSON | "The reviewer scores accuracy, terms, naturalness, level and format, and quotes any mistake so the explainer can fix it." |
| 1:35–1:55 | Results table/bar chart from your real scores | "On our pilot of [20] test cases, [your real result]. One failure we found was [x]; we changed the prompt to [y]." |
| 1:55–2:10 | Next-steps slide | "Next, based on what v2 still gets wrong, we'll build v3, test all 50 cases on three models and get more student ratings. Thank you." |

Tips: zoom the browser to 125% so text is readable; cut pauses; add captions (CapCut/Clipchamp auto-captions are free).
Don't show any result you haven't actually measured.
