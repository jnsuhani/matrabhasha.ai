# 90–150 second video script (M2 component, 2 marks)

Target: **about 2 minutes**. Record your screen (OBS, Windows Game Bar `Win+G`, or Mac `Cmd+Shift+5`) and record voice over it.
Split the voice parts across members if you can, so everyone appears.

| Time | On screen | Voice (say it in your own words, Hindi or English) |
|---|---|---|
| 0:00–0:15 | Title slide: "Matrabhāsha – Team SyntaxAI" + team names | "Hindi-medium first-year students often struggle when CS is taught only in English. Translation tools give stiff Hindi. We built Matrabhāsha to fix that with prompt engineering." |
| 0:15–0:30 | M1 baseline output and Google Translate output side by side, highlight a stiff line | "This is what a simple prompt and Google Translate give. Words like 'पुनरावर्तन' that no student uses, and no sense of the student's level." |
| 0:30–0:50 | `design/workflow.png` | "Our workflow has an explainer prompt with level rules, English terms with a Hindi meaning, a fixed 5-part format and a team-written example. A second reviewer prompt checks it, and a team member does a final check." |
| 0:50–1:20 | Live Gem: `Concept: Stack \| Level: Beginner`, then First-year | "Same concept, two levels. The beginner version uses a daily-life example with no code; the first-year version adds a short snippet and practice questions." |
| 1:20–1:35 | Reviewer Gem returning JSON | "The reviewer scores accuracy, terms, naturalness, level and format, and quotes any mistake so the explainer can fix it." |
| 1:35–1:55 | Results table/bar chart from your real scores | "On our pilot of [20] test cases, [your real result]. One failure we found was [x]; we changed the prompt to [y]." |
| 1:55–2:10 | Next-steps slide | "Next we'll test all 50 cases on three models and get more student ratings. Thank you." |

Tips: zoom the browser to 125% so text is readable; cut pauses; add captions (CapCut/Clipchamp auto-captions are free).
Don't show any result you haven't actually measured.
